# Christian Williams Portfolio

This repository contains the source code for my personal portfolio website.

Live Website:
https://williams0714c-bot.github.io/personal-portfolio/

## Website Sections

Home – Introduction and professional summary  
About – Background and career goals  
Skills – Technical skills related to IT and cybersecurity  
Projects – Displays technical projects and GitHub repositories  
Resume – Embedded resume PDF with download option  
Contact – Contact information and message form  

## Technologies Used

HTML  
CSS  
JavaScript  
GitHub Pages  

## Chatbot Implementation

The website includes a JavaScript-based chatbot that responds to user questions about my:

• Skills  
• Projects  
• Experience  

The chatbot works by detecting keywords from the user's message and returning a predefined response using JavaScript.

Example keywords:

skills  
projects
